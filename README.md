# Milutin & Milica — sajt

Caffe igraonica, rođendaonica i čuvaonica · TC Roda, Kragujevac.

## Objavljivanje na GitHub Pages
1. Napravite novi repozitorijum na GitHub-u.
2. Otpremite ceo sadržaj ovog foldera (`index.html` i folder `uploads/`) u koren repozitorijuma.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
4. Sajt je za minut dostupan na `https://<korisnik>.github.io/<repozitorijum>/`.

`index.html` sadrži sve (stilove, fontove, slike, skripte). Video za mobilni uvod je u `uploads/hero-video.mp4`.
Sajt je responzivan: ista stranica prikazuje desktop i mobilnu verziju.
